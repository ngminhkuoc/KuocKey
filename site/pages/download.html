Hướng dẫn cài đặt

macOS

  1. Mở file vừa tải, kéo KuocKey vào thư mục Applications.
  2. Thoát OpenKey, EVKey hoặc bộ gõ khác nếu đang chạy.
  3. Mở KuocKey, cấp quyền Trợ năng (Accessibility) khi được hỏi.

Windows

  1. Mở file vừa tải. Không cần quyền quản trị.
  2. Thoát OpenKey, EVKey, UniKey hoặc bộ gõ khác nếu đang chạy.
  3. KuocKey nằm ở khay hệ thống. Bấm Alt+Z để chuyển Anh/Việt.

Nếu SmartScreen hỏi, bấm "More info" rồi "Run anyway".

Bản không cần cài (zip, x64 và ARM64) có trên trang phát hành GitHub.

Linux

  1. Cài gói: sudo apt install ./kuockey_*.deb (hoặc sudo dnf install ./kuockey-*.rpm, hoặc sudo pacman -U ./kuockey-*.pkg.tar.zst), rồi đăng xuất và đăng nhập lại.
  2. Vào Cài đặt › Bàn phím › Nguồn nhập, thêm "Vietnamese (KuocKey)".
  3. Chuyển sang KuocKey bằng Super+Space. Bấm Alt+Z để chuyển Anh/Việt.

Nhớ theo trang web chưa có trên Linux; nhớ theo ứng dụng chỉ với ứng dụng X11 trên Wayland.

KuocKey không tự cập nhật và không kết nối mạng. Muốn có bản mới, hãy tải lại từ GitHub. Mã SHA-256 của từng file có trên trang phát hành.
