How to install

macOS

  1. Open the downloaded file and drag KuocKey into Applications.
  2. Quit OpenKey, EVKey or any other Vietnamese input method.
  3. Open KuocKey and allow Accessibility when asked.

Windows

  1. Open the downloaded file. No admin rights needed.
  2. Quit OpenKey, EVKey, UniKey or any other Vietnamese input method.
  3. KuocKey sits in the system tray. Press Alt+Z to switch languages.

If SmartScreen asks, click "More info", then "Run anyway".

Portable zips (x64 and ARM64, no installer) are on the GitHub release page.

Linux

  1. Install the package: sudo apt install ./kuockey_*.deb (or sudo dnf install ./kuockey-*.rpm, or sudo pacman -U ./kuockey-*.pkg.tar.zst), then log out and back in.
  2. Open Settings › Keyboard › Input Sources and add "Vietnamese (KuocKey)".
  3. Switch to KuocKey with Super+Space. Press Alt+Z to switch English/Vietnamese.

Per-website memory is not available on Linux yet; per-app memory works for X11 apps on Wayland.

KuocKey does not update itself and never goes online. To get a new version, download it again from GitHub. SHA-256 checksums for each file are on the release page.
