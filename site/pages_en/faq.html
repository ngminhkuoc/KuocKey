Frequently asked questions

Is KuocKey free?

Yes. KuocKey is free and open source under the GPL-3.0 license. The source code is on GitHub.

How does English/Vietnamese auto-switch work?

Each time you finish a word, KuocKey checks whether the keys you pressed are an English word or a Vietnamese word typed in Telex, then fixes the word and switches mode if needed.

  • In Vietnamese mode, typing "sorry" gives "sory"; KuocKey fixes it to "sorry" and switches to English.
  • In English mode, typing "truowfng" becomes "trường", and KuocKey switches to Vietnamese.

When a word means something in both languages, KuocKey looks at how common each reading is and at the words around it. For example "cos" is usually "có", while "video call thí" is "video call this".

What does "99.73% accuracy" mean?

KuocKey was tested on almost 2 million words: messages, articles, forum comments and news, in Vietnamese, English and a mix of both. The typist never switches by hand. On text that mixes English and Vietnamese, 99.73% of words come out right on average, compared with 97.85% for a normal Telex keyboard.

Does KuocKey run on Windows?

Yes. KuocKey for Windows 10/11 (x64 and ARM64) uses the same typing engine and auto-switch as the Mac app; get it from the download page. The installer needs no admin rights. The first Windows build is not yet code-signed, so Windows SmartScreen may ask once: click "More info", then "Run anyway".

What if KuocKey gets a word wrong?

Press Delete right after. KuocKey puts back exactly the keys you typed and returns to the previous language. If KuocKey has just fixed several words at once, Delete deletes one character as usual.

What if I switch English/Vietnamese myself?

KuocKey switches right away, then pauses auto-switch for 5 seconds so your choice sticks. You can turn this off in the KuocKey window. The default switch shortcut is ⌥Z.

What happens if I press a tone key twice?

The same as in a familiar Telex keyboard: v e r r gives "ver", and KuocKey switches to English. When you finish the word, KuocKey fixes it if needed: "terrible", "sorry", "issue" still come out right.

Does KuocKey remember the language for each app?

Yes. KuocKey remembers whether you use English or Vietnamese in each app, for example Terminal always in English and Zalo always in Vietnamese. Turn on the per-website option to remember each site separately in Safari, Chrome, Edge, Brave, Arc, Vivaldi and Opera. It is off by default because it needs permission to read the address of the open tab.

Is there VNI input?

No. KuocKey supports Telex input and Unicode only.

Does it work with Dvorak, Colemak or AZERTY keyboards?

Yes. KuocKey detects your keyboard layout, so you type Telex by the letters printed on the keys as usual. When you use another language's input method, such as Japanese or Chinese, KuocKey stays out of the way.

Does KuocKey slow down my Mac?

No. KuocKey only checks when you finish a word, which takes about a millionth of a second, and it never reads files or goes online while you type.

Does KuocKey update itself?

No. KuocKey never goes online, so it does not check for new versions. To update, download the new version from GitHub and install it over the old one.

Why does KuocKey need Accessibility permission?

macOS only lets apps with Accessibility permission read the keys you press and replace them with accented letters. Everything happens on your Mac.

Does KuocKey send what I type anywhere?

No. Your keystrokes never leave your Mac. KuocKey makes no network connections. See privacy.

Who makes KuocKey?

KuocKey is designed and developed by Tony Dinh, modified and extended by Quoc Nguyen, based on the open-source OpenKey project by Tuyen Mai. If you use OpenKey, KuocKey brings over your shortcut and the languages remembered for each app the first time it opens. Remember to quit OpenKey before using KuocKey.

Where do I report a bug?

On GitHub Issues. Include the keys you typed, the text that appeared and the text you wanted.

How do I uninstall KuocKey?

Quit KuocKey from the menu bar, then drag KuocKey from Applications to the Trash.
